# Vehicle Data Analysis Project

Welcome to the project.

The goal of this project is to **design a data-analysis function that works with simulated vehicle telemetry data** and produces a useful analysis of the vehicle's behaviour.

## Getting Started

### 1. Clone the repository

Clone this repository to your local machine:

```bash
git clone <repository-url>
cd <repository-name>
```

### 2. Understand the project structure

There are two important files:

```text
DataCreator.py
main.ipynb
```

### `DataCreator.py`

**Do not modify this file.**

`DataCreator.py` contains the functions responsible for generating the simulated vehicle data. A function called:

```python
generate_data(n)
```

is provided, where `n` is the number of data points to generate.

For example:

```python
df = generate_data(1_000_000)
```

generates a large dataset that can be used to simulate the vehicle.

Use these functions as they are provided. **Your task is not to change how the data is generated.**

### `main.ipynb`

**This is where you should do all of your work.**

Use `main.ipynb` to:

* Generate the dataset
* Explore the data
* Design your analysis function
* Create graphs and visualizations
* Perform calculations
* Draw conclusions from the data

## Your Task

Design a function in `main.ipynb` that performs a useful analysis of the vehicle data.

For example:

```python
def analyze_vehicle_data(df):
    # Your analysis here
    pass
```

The type of analysis is up to you.

Some ideas include:

* Speed and acceleration analysis
* Throttle behaviour
* Current and voltage analysis
* Power consumption
* Energy usage
* Relationships between vehicle signals
* Detecting unusual vehicle behaviour
* Identifying acceleration and braking events
* Generating useful statistics
* Creating visualizations

You are encouraged to come up with your own idea.

## Working With the Data

Use `generate_data(n)` from `DataCreator.py` to create a sufficiently large dataset.

For example:

```python
df = generate_data(1_200_000)
```

This creates approximately **20 minutes of simulated vehicle data at 1 ms intervals**.

You can experiment with different values of `n` while developing your analysis.

## Requirements

Your work should:

1. Be completed in `main.ipynb`.
2. Use the data generated by `DataCreator.py`.
3. Include at least one meaningful analysis function.
4. Work with a reasonably large dataset.
5. Produce a useful result, such as calculations, statistics, graphs, or detected events.
6. Include enough explanation in the notebook that someone else can understand your approach.

### Important

**Do not edit `DataCreator.py`.**

If you think the data-generation functions could be improved, leave them unchanged and work with the data that they provide.

## Completing the Project

Once your analysis is complete:

1. Make sure `DataCreator.py` has not been modified.
2. Make sure all of your work is in `main.ipynb`.
3. Test your analysis with a large dataset.
4. Clean up your notebook and make sure the results are understandable.
5. Save the completed notebook.
6. Commit your changes.
7. Push the project back to the repository.
8. Send the completed project back to me for review.

## Have Fun

There is no single correct analysis :)

The objective is to take the simulated vehicle data and find something useful or interesting within it.
